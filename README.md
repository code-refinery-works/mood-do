# MoodDo (ムード・ドゥ) 🌿🔥🌙🎯

> **その日の「気分」に寄り添い、デザインと言葉が変化するメンタルケア連動型Todoアプリ**

「やる気が出ない日は無理をさせず、絶好調の日は背中を押す」
日々のコンディションに合わせて、アプリのテーマカラー、フォント、励ましメッセージ、タスク入力のハードルがガラリと変化します。

---

## ✨ 主な機能

- **朝一番の気分チェックイン**
  - 🔥 **やる気MAX (Energy)**: 鮮やかなオレンジ＆熱血応援メッセージで一気にタスクを消化！
  - 🌿 **のんびり (Chill)**: 優しいミントグリーンと柔らかなUIで「マイペース」を推奨。
  - 🌙 **省エネ (Low)**: 目に優しいダークパープル。「生きてるだけで100点満点」の超低負荷モード。
  - 🎯 **集中 (Focus)**: 無駄を削ぎ落としたスタイリッシュなダークUI。目の前の1タスクに没頭。
- **リアルタイム・テーマスイッチ**
  - 気分をワンタップで切り替えると、背景、カード、入力欄、プレースホルダー、格言がシームレスに変化。
- **ローカルストレージ永続化**
  - 設定した気分と作成したTodoはブラウザに自動保存されます。

## 🚀 使い方

ブラウザで `index.html` を開くだけで即座に動作します。

```bash
# リポジトリのクローン
git clone https://github.com/code-refinery-works/mood-do.git
cd mood-do

# ブラウザで開く
open index.html
```
